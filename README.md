# Pie Game — Jogo da Velha

Jogo da velha contínuo, feito com HTML, CSS e JavaScript puro (sem dependências).

## Como jogar

Abra o arquivo `index.html` no navegador ou sirva a pasta localmente:

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

Depois acesse <http://127.0.0.1:8000>.

## Funcionalidades

- **Contra a CPU** (minimax, joga sempre o melhor lance) ou **2 jogadores**.
- Mensagem de **vitória, derrota ou empate** ao final de cada rodada.
- **Reinício automático em 3 segundos** após o fim da partida.
- Placar acumulado entre rodadas, com opção de zerar.
- Atalhos de teclado: teclas **1–9** jogam e **R** reinicia a rodada.
- Layout responsivo para celular.
